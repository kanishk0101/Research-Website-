# The Excitation Dynamics & Organic Materials Group Website

This is a modern, responsive, and performance-optimized academic research group website built for the Excitation Dynamics & Organic Materials Group led by Prof. Neeraj Agarwal at the UM-DAE Centre for Excellence in Basic Sciences.

## Features

- **Modern Tech Stack**: Built with [Next.js App Router](https://nextjs.org/), React 19, and TypeScript.
- **Styling & Animations**: Fully responsive design using Tailwind CSS v4, with smooth transitions and layout animations powered by Framer Motion.
- **Component-Driven Architecture**: Modular UI components (Cards, Buttons, Badges, Accordions) for easy maintenance and scalability.
- **Dynamic Content**: Sections for Research Highlights, Publications, News, and Group Members.
- **Optimized Assets**: Next.js image optimization and fast page loads via static generation.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the local site.

## Deployment

This project is configured for seamless deployment on [Vercel](https://vercel.com).
